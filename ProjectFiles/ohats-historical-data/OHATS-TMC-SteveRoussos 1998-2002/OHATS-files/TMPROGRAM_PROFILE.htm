COMPLETE THE TUTOR/MENTOR PROGRAM PROFILE TO HAVE YOUR PROGRAM LISTED IN THE T/MC PROGRAM LOCATOR

 

The Tutor/Mentor Connection's Program Profile is used to compile information on tutor/mentor programs serving the Chicago region. The T/MC seeks to circulate the survey to every known program each spring and have the information returned by mid July. Information from the Program Profile is use to create the T/MC Directory, T/MC maps and T/MC on-line databases. These are used by potential volunteers, donors and families looking for programs.

The Lend-A-Hand Grant Program at the Chicago Bar Association/Foundation requires all grant-seekers to submit a Program Profile with their grant applicaiton. As a result, the T/MC received more than 50 completed surveys each May at the end of the grant making cycle. As more charitable foundations adopt the T/MC Program Profile as part of grant making, the information Chicago has to understand the availability and distribution of non-school tutor/mentor programs will greatly increase.

If you are a tutor/mentor program and would like to update your information, or add your information to the T/MC database, please print this survey, fill it out, and send it to: Cabrini Connections, Tutor/Mentor Connection. 800 W. Huron, Chicago, IL. 60622
