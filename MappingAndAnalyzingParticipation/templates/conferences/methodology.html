Methodology

This project documents a reproducible pipeline for transforming raw conference attendance records into analyzable social network data. Each stage below is codified — the inputs, transformations, and outputs are explicit so the process can be repeated, extended, or adapted for future events.

Normalization & Classification

3
Network Construction & Export
Normalized attendance records are transformed into graph structures: organizations become nodes (attributed with sector, event count) and relationships become edges (co-attendance, bipartite links, or hierarchical layers). Three graph models are supported, each answering a different analytical question.
Org ↔ Event (Bipartite) Which organizations attended which events? Node size reflects participation depth.
Org ↔ Org (Co-attendance) Which organizations share conference history? Edge weight = number of shared events.
Event → Sector → Org (Three-layer) How does participation flow from events through sector types to individual organizations?
nodes.csv edges_org_event.csv edges_org_org.csv edges_3layer.csv
Exports are formatted for direct import into Kumu.io or Gephi — no post-processing required.
4
Visualization & Analysis
Network exports feed into two visualization tracks: in-platform rendered maps (built with NetworkX and Matplotlib) and interactive external tools (Kumu, Gephi). The analytics dashboard surfaces aggregate patterns (sector distribution, top organizations, attendance trends over time) providing the interpretive layer that turns the network into insight.

Because every prior stage is reproducible (the same source CSV always produces the same normalized records, the same graph exports, and the same visualizations) results can be independently verified or regenerated as the dataset is updated.
