Three views of the Tutor/Mentor conference participation network (1994–2014). Maps 1 and 2 are interactive (Kumu.io). Map 3 is rendered live from the database and may take a few seconds to load.

Map 1 — Organization–Event Bipartite Network (Interactive)

Each organization (colored by sector) is connected to every conference event it attended. Interactive — click any node to explore connections, use the legend to filter by sector. Powered by Kumu.io with live data from this platform.

Map 2 — Organization–Organization Co-attendance Network (Interactive)

Organizations connected by shared conference attendance. Edge weight = shared conferences (minimum 3). Node size = conferences attended. Color encodes SNA sector. Interactive — click any node to explore connections, filter by sector below the map.

Map 3 — Event → Sector → Organization (Three-Layer, 2004–2010)

A three-layer structural view focused on the peak attendance years (2004–2010). Left layer: conference events. Center: SNA sectors. Right: organizations attending ≥4 events in the window. Shows how sectors bridge events and organizations, and which orgs anchor each sector.
