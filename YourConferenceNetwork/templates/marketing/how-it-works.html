Simple Setup

How It Works

From CSV export to network map in under five minutes.

1

Prepare Your CSV

Export your attendance records from your registration system (Eventbrite, Google Sheets, etc.) as a CSV. Our standard column format matches common registration exports:

UniqueID, First, Last, Organization - CLEANED, SNA Category - CLEANED, Conference, Month, Year, State, ...

Column headers are flexible — see the documentation for the full spec and optional columns.

# Example CSV rows
UniqueID,First,Last,Organization - CLEANED,SNA Category - CLEANED,Conference,Month,Year
1001,Maria,Chen,Chicago Youth Network,Program,05/2005,5,2005
1002,James,Lee,City of Chicago,Government,05/2005,5,2005
1003,Sarah,Kim,Harris Foundation,Foundation,05/2005,5,2005
2

Deploy with Docker

Clone the repo, copy your .env file, and run Docker Compose. The app starts, runs migrations, and is ready to load your data.

$ git clone https://github.com/your-org/yourconference.network
$ cd yourconference.network
$ cp .env.example .env # edit SECRET_KEY
$ docker compose up -d
$ docker compose exec web python manage.py load_data --csv /data/my_conferences.csv

Requirements

  • Docker & Docker Compose (any recent version)
  • Any Linux server or local machine (macOS/Windows with Docker Desktop)
  • Your attendance CSV exported from any registration system
