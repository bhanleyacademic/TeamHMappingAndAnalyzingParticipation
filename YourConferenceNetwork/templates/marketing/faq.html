Getting Started

What exactly does this tool analyze?

YourConference.Network analyzes conference attendance records — who attended which events, from which organizations, and in which sector categories. It produces network maps, sector analytics, and data exports showing how organizations are connected through shared conference attendance.

What format does my CSV need to be in?

Your CSV needs columns for: name fields (First, Last), organization name, SNA/sector category, conference identifier, month, and year. A UniqueID column is recommended. State and ZIP are optional for geographic filtering. See our How It Works page for the full column spec.

What are "SNA categories"?

SNA (Social Network Analysis) categories classify organizations into sector types: Program, Resource, College, Intermediary, Business, T/MC, Government, K-12 School, Faith, Foundation, and Other. The platform normalizes raw category labels from your data into these canonical categories automatically.

How large a dataset can it handle?

The self-hosted version with SQLite handles up to ~50,000 records without performance issues. For larger datasets, switch to PostgreSQL (documented in SELF_HOSTING.md). Network maps for large datasets may take 10–30 seconds to render.

Self-Hosting

What do I need to self-host?

Docker and Docker Compose (any recent version). That's it. It runs on any Linux server, macOS, or Windows with Docker Desktop. A $5–10/month VPS (DigitalOcean, Hetzner, etc.) is more than sufficient for most organizations.

How do I update to a new version?

Pull the latest code from GitHub, rebuild the Docker image, and restart. docker compose pull && docker compose up -d --build. Migrations run automatically on startup. Your data is preserved in the mounted volume.

Can I run it on a shared host (no Docker)?

Yes — it's a standard Django app. Install Python 3.12, install dependencies from requirements/selfhosted.txt, configure your environment variables, run python manage.py migrate, and serve with Gunicorn behind Nginx. Docker is just the recommended path for simplicity.

Data & Privacy

Does YourConference.Network see my data?

When self-hosting, your data never leaves your server — we have no access to it at all. When using cloud hosting (coming soon), your data is stored on our infrastructure. We do not sell or share your data.

What data does the platform store?

Only what's in your CSV: names, organization names, sector categories, conference identifiers, and location fields. No sensitive personal data (email, phone, SSN) is expected or used by the analytics engine.
