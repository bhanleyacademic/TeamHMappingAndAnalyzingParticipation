Your Conference Network

Network Maps

Three views of your participation network: org–event bipartite, org–org co-attendance, and a three-layer event → sector → org hierarchy. Generated live from your data.

See example maps

Sector Analytics

Interactive stacked bar charts showing attendance per event by sector type. Filter by year, sector, or state. Instantly see which organization types anchor each conference.

View chart

Network Data Export

Download nodes and edges CSVs ready for Kumu.io and Gephi. Four export modes: nodes, org–event edges, org–org co-attendance (weighted), and 3-layer event–sector–org edges.

Try exports

Data Quality Tools

Built-in normalization maps raw sector labels to canonical categories (Program, Business, Government, etc.). Quality report shows missing data, raw vs. normalized distributions.
