You need attendance records from conferences or events. Each row should represent one attendee at one event. Required fields: Organization name, Sector/category, and Conference date (MM/YYYY format). Sectors classify the type of organization attending (e.g., Program, Business, Government, College, Faith, Foundation). In real data, the same sector gets recorded many ways — "program/faith", "Program-Faith", "Program (faith)" — our normalization pipeline maps all variants to a standard set of 11 canonical categories automatically. You can also provide pre-cleaned sector data in the "SNA Category - CLEANED" column if you've already standardized it.
