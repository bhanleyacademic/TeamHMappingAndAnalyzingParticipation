1Installation

Follow the steps below to setup your site template:

  1. Unzip the downloaded package and open the Template folder to find all the template files. You wil get Ntec folder in there. You need to upload this folder to your hosting web server using FTP or cPanel in order to use it on your website.
  2. Below is the folder structure you will see in your website root directory:
    • Ntec/css - Stylesheet files
    • Ntec/fonts - Icon/fonts files
    • Ntec/images - Image files
    • Ntec/js - js files
    • Ntec/assets - plugins files
  3. You need to upload all or specific HTML files as per your need.
  4. And now you are ready to go to generate your webiste with this awesome template.

3Favicon Settings

Favicon Will be found in head section.

        
        <link rel="icon" type="image/png" sizes="32x32" href="assets/favicon.ico">

4Logo Settings

The Logo will be found in the Theme Main Menu section.

        <div class="d-flex logo order-lg-0"><a href="index.html" class="d-block"><img src="assets/img/logo/header-logo-01.png" alt=""></a></div>

You can replace any .jpg .png .svg logo. And set the width according to your logo size.

5Fonts Settings

In Ntec we use Urbanist ,KumbhSans font.
You can change both fonts form css/style.css file: 

            @import url('https://fonts.googleapis.com/css2?family=Kumbh+Sans:wght@300;400;500;600;700;800;900&display=swap');
            @import url('https://fonts.googleapis.com/css2?family=Urbanist:wght@400;500;600;700;800;900&display=swap');

7CSS Structure

The style.css file contains all of the specific stylings for the page. The file is separated into sections using:

    This file includes core bootstrap styles

  • bootstrap-icons.css

    This file contains bootstrap icon library

    Source
